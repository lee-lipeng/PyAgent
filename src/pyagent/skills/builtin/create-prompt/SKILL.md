# 创建提示词（Meta-Skill）

本技能指导你将重复性任务模式固化为可复用的提示词模板。

## 何时使用

- 用户在对话中反复执行同类任务（如解释代码、生成测试、重构）。
- 用户要求将某个工作流"固化""模板化""保存下来"。
- 用户要求创建 `.prompt.md` 或提示词文件。

## 创建流程

### 1. 从对话中提取模式

回顾当前对话历史，识别重复出现的任务模式：
- **核心任务**：反复执行的操作是什么？
- **隐含输入**：是否有选中的代码、文件类型、上下文等隐含输入？
- **输出格式**：期望的输出风格或结构是什么？
- **变化部分**：每次执行中哪些是变化的，哪些是固定的？

### 2. 澄清需求

如果没有明确的模式，向用户询问：
- 这个提示词要帮助完成什么任务？
- 需要接受参数还是使用固定上下文？
- 是工作区级别还是个人级别？

### 3. 编写模板

提示词模板结构：

```markdown
---
name: prompt-name
description: 一句话说明这个提示词做什么。
---

# 提示词标题

## 任务
描述要完成的核心任务。

## 输入
- {{input}}：说明输入参数

## 输出格式
描述期望的输出格式。

## 步骤
1. 具体步骤
2. 每步的注意事项

## 约束
- 需要遵守的规则
```

**写法要点**：
- 用 `{{变量名}}` 标记可替换部分。
- 保持指令具体可执行，避免"适当处理"这类模糊描述。
- 包含至少一个示例输入和期望输出。

### 4. 保存文件

将提示词保存到合适位置：
- 工作区级：`<project>/.pyagent/prompts/<name>.prompt.md`
- 用户级：`~/.pyagent/prompts/<name>.prompt.md`

### 5. 迭代优化

1. 写出初稿并保存。
2. 识别最模糊或薄弱的部分，向用户确认。
3. 定稿后总结提示词用途，建议示例调用方式。
4. 提议相关的下一步定制。
