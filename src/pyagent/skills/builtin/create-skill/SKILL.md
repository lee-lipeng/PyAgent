# 创建技能（Meta-Skill）

本技能指导你为 PyAgent 创建新的 SKILL.md 技能文件。

## 技能结构

一个技能是一个目录，至少包含 `SKILL.md`：

```
skill-name/
├── SKILL.md          # 必需：元数据 + 指令正文
├── scripts/          # 可选：可执行脚本
├── references/       # 可选：按需加载的参考文档
└── assets/           # 可选：模板、资源文件
```

## 放置位置

按优先级选择放置目录：

| 优先级 | 场景 | 路径 |
|--------|------|------|
| 1 | 用户明确指定路径 | 使用该路径 |
| 2 | 系统内置技能 | `src/pyagent/skills/builtin/<name>/` |
| 3 | 用户级技能 | `~/.pyagent/skills/<name>/` |
| 4 | 项目级技能 | `<project>/.pyagent/skills/<name>/` |

## 创建流程

### 1. 收集意图

向用户确认以下信息（不确定时主动询问）：
- **技能名**：小写字母 + 数字 + 连字符，如 `pdf-processing`。
  不能以连字符开头或结尾，不能有连续连字符。
- **触发条件**：什么情况下应该使用这个技能？（写入 description）
- **工作流程**：技能被激活后应该执行哪些步骤？
- **前置条件**：使用前需要什么环境或依赖？
- **已知陷阱**：有哪些常见的失败模式需要避免？

### 2. 编写 frontmatter

```yaml
---
name: skill-name
description: >-
  一句话说明技能做什么。接着说明何时触发。
  触发词：关键词1、关键词2。
---
```

**description 写法要点**：
- 以"做什么"开头，再说明"何时使用"。
- 包含具体的触发关键词，帮助 LLM 识别相关任务。
- 控制在 250 字符以内，简洁有力。
- 不要写成工作流摘要——description 驱动匹配，不是说明书。

### 3. 撰写指令正文

正文结构（按需选用）：

```markdown
# 技能标题

简短概述（1-2 句话）。

## 何时使用
- 具体的触发场景列表

## 前置条件
- 使用前需要满足的条件

## 工作流程
1. 具体可测试的步骤
2. 每步只做一件事

## 注意事项
- 只记录实际发生过的失败模式
- 不要罗列理论上的陷阱

## 验证
- 完成后如何确认技能执行成功
```

**正文写法要点**：
- 用祈使句（"执行 X""检查 Y"），不要用"你应该…"。
- 步骤要**具体可测试**，不要写"优化性能"这种模糊指令。
- 保持正文 < 500 行；过长的内容拆到 `references/` 子文件。
- 添加适量中文注释，拒绝 AI 味的冗余描述。

### 4. 写入文件

用 `write_file` 工具将 `SKILL.md` 写入选定目录。
技能名必须与目录名一致。

### 5. 验证

- 确认 frontmatter 的 `name` 与目录名一致。
- 确认 `description` 非空且包含触发词。
- 确认正文以 `#` 标题开头。
- 告知用户技能路径和如何调用（`/skill:<name>`）。
